## CSS Hero Section Gradient

Hero section uses a dark gradient:
- Top: #1a1a2e
- Bottom: #16213e

Use these exact values for consistency.

## Mobile Breakpoints

Responsive design uses mobile-first approach with breakpoints at:
- 900px
- 768px
- 600px

When adding CSS media queries, use these breakpoints only.

## Framework and Language Policy

No JavaScript in this project.

The site must be:
- Pure HTML5
- CSS3 only
- No frameworks
- No build tools

All effects must be CSS-based (animations, hover states).

## Why

Keep the project:
- Simple
- Maintainable
- Easy to deploy
